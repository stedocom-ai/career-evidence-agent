# 课程日志检索练习（虚构）

本文为软件演示材料，所有经历均为虚构。

## 需求

把课程实验日志保存到本地，按关键词找到相关记录，并显示记录来源。

## 实现

使用 Python 和 SQLite 保存并查询课程实验日志。

编写命令行导入程序，将 UTF-8 文本按段落保存，记录文件标题与段落编号。

使用参数化 SQL 查询，避免把输入直接拼接为 SQL。

使用 unittest 检查重复导入、空查询、中文关键词和数据库重新打开后的查询结果。

## 边界与下一步

当前实现是本地关键词检索。尚未接入 LLM 工具调用，也没有 Docker 部署记录。

下一步可以添加结构化工具接口与模型调用记录，再用固定案例检查输出依据。
